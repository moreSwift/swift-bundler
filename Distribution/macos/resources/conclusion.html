Swift Bundler is installed

The tool has been installed at /usr/local/bin/swift-bundler and /usr/local/bin/sbun.

Open a new terminal and run: 

swift-bundler --version
swift-bundler --help

To uninstall, remove the binary and forget the package receipt: 

sudo rm /usr/local/bin/swift-bundler
sudo rm /usr/local/bin/sbun
sudo pkgutil --forget dev.moreswift.swift-bundler
